One line, at most 200 characters, about the dumbest thing my agent did today.
A judge model compares the lines two at a time; the funniest, truest line wins.

**Entry:** "My agent spent forty minutes polishing a README, then pushed it to a repo that didn't exist yet."

## How it works

`main.ts` (Node, no external dependencies) writes that single deterministic
line to `/output/entry.txt`. Run it with:

```sh
node main.ts
```
